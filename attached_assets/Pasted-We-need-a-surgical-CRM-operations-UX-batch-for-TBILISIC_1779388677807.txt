Task 1 — TBS AIR PARKING service wrench indicator

Goal:
In TBS AIR PARKING vehicle cards, if the vehicle currently has an active service record with status SCHEDULED or IN_PROGRESS, show a small wrench/tool icon integrated into the card design.

Requirements:
- Completed service records must not show the icon.
- Cancelled service records must not show the icon.
- Only active statuses count:
  - SCHEDULED
  - IN_PROGRESS
- The icon should be small, visually clean, and fit the existing dark card design.
- It should not make the parking card taller unless necessary.
- Show tooltip/title:
  - "Scheduled service" for SCHEDULED
  - "Service in progress" for IN_PROGRESS
- If both statuses exist for the same vehicle, prefer showing IN_PROGRESS as the stronger operational state.

Backend approach:
In listParkingByZone() in admin-parking.service.ts:
- Keep existing response structure.
- Add optional service status metadata to each assignment, for example:
  - activeServiceStatus: "SCHEDULED" | "IN_PROGRESS" | null
  - activeServiceId?: number | null if easy and safe
- Avoid duplicate parking rows if a vehicle has multiple service records.
- Do not use a direct join that duplicates parking assignments.
- Preferred safe approach:
  1. Fetch active parking rows as currently.
  2. Collect vehicleIds.
  3. Query maintenance/service records for those vehicleIds where status IN ("SCHEDULED", "IN_PROGRESS").
  4. Build a map by vehicleId using priority IN_PROGRESS > SCHEDULED.
  5. Merge activeServiceStatus into each parking row.

CRM approach:

- Extend ParkingEntry type with activeServiceStatus?: string | null.
- Import Wrench icon if needed.
- Render a small wrench button/icon next to plate/model or near the action icons.
