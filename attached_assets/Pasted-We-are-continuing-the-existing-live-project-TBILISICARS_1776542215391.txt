Phase 2 — WEBSITE Booking vehicle selection redesign
Target the Booking vehicle-selection step/page only.
The current problem is that vehicles appear too chaotic when many results are shown. We need a premium, structured layout.

Approved target behavior:
- Vehicles must be displayed grouped by category in vertical order
- All non-empty categories should appear on the page in the approved order
- The user scrolls down the page and sees category after category
- Each category is a distinct section with its own header
- Empty categories should not render
- Within each category, only vehicles belonging to that category render

Desired section pattern:
Category Header
- Category name
- Small meta text such as “From €X/day • Y cars available” if this can be derived safely from current data
- Elegant spacing and hierarchy
Then the vehicles of that category

Responsive rendering:
- Mobile: vertical category sections; within each category, vehicles should feel touch-friendly and polished. Replit should decide whether horizontal swipe cards or a compact stacked layout is better based on current code constraints, but the result must be clean and not chaotic.
- Desktop: same category order, but a premium grid layout is preferred within each section rather than a mobile-only carousel feeling.

Very important:
Do not require the user to click a category first.
All categories should already be shown on the page in vertical sequence.
This is NOT a tabs-first experience.
This is a structured scroll experience.
