Function behavior:

Input:

- dropoff datetime

Output:
- chargeableDays

Rules:

1. Calculate base day difference
2. Apply minimum = 2 days
3. Apply grace period:

- If return time exceeds exact boundary by:
  - ≤ 120 minutes → NO extra day

Pickup: 01 Apr 12:00
Return: 03 Apr 14:00 → 2 days
Return: 03 Apr 14:01 → 3 days
