6. Accounting expanded row partner payable section
Modify:
artifacts/crm/src/pages/Accounting.tsx

Existing expanded row loads:
GET /api/admin/accounting/:id

Inside the existing expanded-entry block, add compact Partner section.

Trigger:
if expandedEntryData.vehicle_partner_id != null

Header:
- Partner: vehicle_partner_name
- Vehicle: vehicle_plate
- Booking: #booking_ref_id
- Source income: current ledger row amount/currency
- Agreement notes: vehicle_partner_agreement_notes if present

If no existing partner_payable_id:
Show:
- Amount input, always empty
- Currency select GEL/USD/EUR, default GEL
- Add to Pending button

POST /api/admin/partners/payables payload:
{
  partnerId: expandedEntryData.vehicle_partner_id,
  bookingId: expandedEntryData.booking_id,
  vehicleId: expandedEntryData.related_vehicle_id,
  sourceIncomeAccountingEntryId: current entry id,
  amount,
  currency
}

On 409:
Show inline error:
“A payable already exists for this income entry (status: PENDING/PAID). Only a canceled payable may be replaced.”

If partner_payable_status === "PENDING":
Show:
- Pending badge
- amount/currency
- Edit pending inline:
  - amount
  - notes
  - save/cancel
- Cancel button
- Mark as Paid button with confirmation dialog

Actions:
PATCH /api/admin/partners/payables/:id
POST /api/admin/partners/payables/:id/cancel
POST /api/admin/partners/payables/:id/mark-paid

After every payable mutation:
refresh the expanded entry data by re-calling GET /api/admin/accounting/:id.

If partner_payable_status === "PAID":
Show:
- Paid badge
- amount/currency
- paid date
- generated expense entry id/link if available

If partner_payable_status === "CANCELED":
Show:
- Canceled badge
- Create New Payable option that resets to empty input

8. Edit warnings
In Accounting Add/Edit Entry modal:
When editing an entry, fetch or pass GET /api/admin/accounting/:id context to detect partner_payable_id.

If editing INCOME and linked non-canceled partner payable exists:
Show yellow warning:
“This entry has a linked partner payable (#N). Changing the amount here does not automatically update the payable — finance must adjust it manually.”

If editing EXPENSE and linked partner payable exists:
Show yellow warning:
“This expense was auto-generated from partner payable #N. Editing here does not update the payable. All partner/booking/vehicle links are preserved.”

Do not block saving.
Warnings are informational only.
