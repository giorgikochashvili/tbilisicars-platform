==================================================
PHASE 3 GOAL
==================================================

Implement fullscreen playlist slideshow mode for office/airport screens.

This is separate from:
- vehicle presentation carousel
- compare carousel

Fullscreen playlist slideshow should play selected playlist slides automatically.

==================================================
REQUIRED BEHAVIOR
==================================================

1. Start Fullscreen from playlist

In the Playlists tab:
- Each playlist should have a “Start Fullscreen” button.
- Clicking it should open launch settings before starting.

2. Launch settings modal

Before starting slideshow, staff chooses:

- Language:
  - English
  - Hebrew
  - Arabic

- Currency:
  - USD
  - EUR

- Show Price:
  - ON
  - OFF

3. Slideshow player

After launch:
- open a fullscreen presentation/player view
- hide CRM/admin UI visually
- use playlist items in their saved order
- each slide uses its own duration_seconds
- automatically advance slides
- loop playlist continuously
- allow manual next/previous with arrows
- allow Escape / Exit to close slideshow

4. Slide content

Each slide should display:
- large vehicle image from existing vehicle model image_url
- title in selected language
- body/selling text in selected language
- badge in selected language if exists
- optional showroom daily price if Show Price is ON

Price rules:
- price comes only from showroom_model_prices
- USD is manual stored price
- EUR is calculated using showroom_settings.usd_to_eur_rate
- do NOT use Rates/Pricing/Booking logic
- if Show Price is OFF, no price should appear
- if no showroom price exists, omit price or show no price silently

Language rules:
- English uses EN fields
- Hebrew uses HE fields and RTL layout where appropriate
- Arabic uses AR fields and RTL layout where appropriate
- If selected language text is missing, safely fallback to English if available

5. Visual style

Player should feel like a premium airport/office display:
- dark/premium Tbilisicars background
- very large vehicle image
- clean badge/title/body text
- optional price in a nice foreground panel
- no admin tables
- no technical specs
- no clutter
- suitable for TV and tablet screens

6. Controls

In slideshow mode:
- minimal Exit button
- minimal previous/next arrows
- optional small progress indicator or slide counter
- no heavy controls visible by default
- controls can be subtle
