# SEO Phase Task 1 — Noindex Booking Page + Remove Booking From Sitemap

We are starting a controlled SEO/Google visibility phase for the live TBILISICARS production project.

This task must be extremely narrow and safe.

What & Why:
The public /booking page is a transactional funnel page with dynamic query parameters. It should not be indexed by Google and should not be listed in sitemap.xml. It currently has canonical metadata but no robots noindex directive, and sitemap.xml includes /booking. This can create duplicate/parametric indexing risk and waste crawl budget.

Scope:
1. In artifacts/website/src/pages/Booking.tsx:
   - Inside the existing <Helmet> block for the Booking page, add:
     <meta name="robots" content="noindex,follow" />
   - Keep the existing canonical tag unchanged.
   - Do not change any booking UI, booking state, API calls, query parameter handling, pricing, availability, payment, or booking logic.

2. In artifacts/website/public/sitemap.xml:
   - Remove only the <url> block for:
     https://tbilisicars.com/booking
   - Do not remove or change other public URLs.
   - Keep private routes excluded as they already are.

Out of Scope:
- Do not touch API/backend.
- Do not touch CRM.
- Do not touch DB/schema/migrations.
- Do not change booking logic, pricing, availability, payment, extras, confirmation emails, PDF vouchers, or customer cabinet.
- Do not redesign any page.
- Do not add schema changes in this task.
- Do not implement city landing page improvements in this task.

Done Looks Like:
- Booking.tsx Helmet contains:
  <meta name="robots" content="noindex,follow" />
- sitemap.xml no longer contains https://tbilisicars.com/booking.
- sitemap.xml still contains the other public website URLs.
- No unrelated files changed except build/generated files if Replit rebuilds.
- Website typecheck/build passes.

Testing checklist:
- Confirm source sitemap has no /booking entry.
- Confirm Booking.tsx Helmet has noindex,follow.
- Run website typecheck/build if available.
- Report exact changed files.
