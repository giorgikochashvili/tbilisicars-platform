3. Add partner_payable table
Create partner_payable with:
- id
- partner_id not null FK partner.id
- booking_id nullable FK booking.id ON DELETE SET NULL
- vehicle_id nullable FK vehicle.id ON DELETE SET NULL
- source_income_accounting_entry_id not null FK accounting_entries.id
- amount numeric(12,2) not null
- currency accounting_currency_enum not null default GEL
- status enum PENDING / PAID / CANCELED default PENDING
- notes
- created_by_admin_id nullable FK admins.id
- paid_by_admin_id nullable FK admins.id
- paid_at
- expense_accounting_entry_id nullable FK accounting_entries.id ON DELETE SET NULL
- created_at / updated_at
- indexes for partner_id, source_income_accounting_entry_id, status, booking_id

Add DB-level unique partial index:
one non-canceled payable per source_income_accounting_entry_id.

Use:
WHERE status != 'CANCELED'

This must block both PENDING and PAID duplicates.
Only a CANCELED payable may allow creating a new one.

7. Partner payable create validation
When POST /admin/partners/payables is called, validate:
- sourceIncomeAccountingEntryId exists
- source entry type is INCOME
- no existing non-canceled payable for the same source income entry
- amount > 0
- currency is valid GEL / USD / EUR
- if income entry vehicle has vehicle.partner_id, request partnerId must match that vehicle.partner_id
- if bookingId is provided, it must match the income entry related booking context
- if vehicleId is provided, it must match the income entry related vehicle context
Return 400 for validation failures, 404 for not found, 409 for duplicate non-canceled payable.

8. Mark as Paid transaction
POST /admin/partners/payables/:id/mark-paid must:
- run inside one db.transaction
- lock payable row FOR UPDATE
- reject if status is not PENDING
- reject if expense_accounting_entry_id is already set
- use existing getExchangeRate / convertToGel helpers exactly as existing accounting entries do
- insert exactly one EXPENSE accounting entry:
  - type EXPENSE
  - category Partner Vehicle Payout
  - amount/currency from payable
  - relatedBookingId from payable.booking_id
  - relatedVehicleId from payable.vehicle_id
  - adminId from current session
  - notes must include partner name, booking reference/id, vehicle plate, and source income entry id
- update payable to PAID
- set paid_at, paid_by_admin_id, expense_accounting_entry_id
- emit audit logs for partner_payable marked paid and accounting_entry partner payout created
- return updated payable and new expense entry id

Do not change exchange rate logic. Only consume existing helpers.
