We need to plan the next small phase for TBILISICARS CRM Digital Showroom.

Feature:
Digital Showroom currently shows all vehicle models from the system, grouped by category. This is not ideal for a showroom/sales tool. We need staff-controlled visibility and ordering.

IMPORTANT:
PLAN MODE ONLY.
Do not modify files.
Do not implement anything yet.

Current state:
- Digital Showroom exists in CRM.
- It has Vehicles, Slides, Playlists, Prices.
- It uses existing vehicle model images read-only.
- It has showroom-only prices.
- It has slides/playlists/fullscreen slideshow.
- It is isolated from booking/pricing/payment/public website/upload logic.
- Recently deployed successfully to production.

Problem:
The Vehicles tab currently displays every vehicle model available in the system. We need to control which models appear in Digital Showroom and in what order.

Example issue:
“7 Seater SUV” appears first, which feels wrong for a showroom sales experience. We want more common/sales-friendly categories/models to appear first, such as Economy, Sedan, Crossover/SUV, etc.

==================================================
GOALS
==================================================

Plan a safe implementation for:

1. Show / Hide vehicle models in Digital Showroom
- Staff should be able to decide which vehicle models appear in Digital Showroom.
- Hiding a model from Digital Showroom must NOT delete it from Fleet.
- It must NOT affect website visibility.
- It must NOT affect booking availability.
- It must NOT affect pricing/rates.
- It must only affect Digital Showroom display.

2. Manual ordering of showroom models
- Staff should be able to control the order of models shown inside Digital Showroom.
- Avoid random/DB/alphabetic order as the main showroom order.
- Simple Up/Down buttons or numeric order is acceptable.
- Drag-and-drop is NOT required.

3. Category ordering
- Categories should display in a sales-friendly order, not random order.
- Example desired rough order:
  - Economy
  - Standard / Intermediate Sedan
  - Full-Size Sedan
  - Crossover / Intermediate SUV
  - Full-Size SUV
  - Premium SUV
  - Business Class
  - 7 Seater SUV
  - Off-Road
  - Sports / Cabrio / Special
- This can be a safe frontend priority map if that is simpler than DB-driven category ordering.
- Do not overengineer category ordering in this phase.

4. Manage Showroom Models UI
- Add a simple management UI inside Digital Showroom, likely in Vehicles tab.
- Example: “Manage Showroom Models” button.
- It should allow:
  - show/hide toggle per model
  - view model name/category/image
  - control order with Up/Down or order number
  - save changes
- Keep UI simple and staff-friendly.

Suggested table:
showroom_model_settings
- id
- vehicle_model_id

- created_at

Important:

Default behavior:
- Existing models should remain visible by default unless staff hides them.
- This avoids suddenly emptying the production showroom after deploy.
- If a model has no showroom_model_settings row, treat it as visible with a safe default order.
