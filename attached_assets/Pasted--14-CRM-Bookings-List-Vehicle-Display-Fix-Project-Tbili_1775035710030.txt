#14 - CRM Bookings List Vehicle Display Fix
Project: Tbilisicars CRM&WEB

Important:
This project is already fully built and interconnected inside Replit. Make this as a minimal, safe fix only. Do not refactor unrelated logic, routes, APIs, or pages. Do not break booking creation, website bookings, CRM bookings, vehicle assignment, or booking detail flows.

==================================================
ISSUE
==================================================

In the Bookings page, the "Vehicle & Customer" column currently shows "No vehicle assigned" unless a specific vehicle is assigned.

This is not correct for many valid bookings.

Example:
- A booking may already have a selected Brand + Model
- But a specific physical vehicle may not yet be assigned
- In that case, the Bookings list should still show the booked vehicle model

Current incorrect behavior:
- If no exact vehicle is assigned yet, the list shows "No vehicle assigned"

Required correct behavior:
- If booking has a selected vehicle model, show that model in the Bookings list
- If a specific vehicle is later assigned, also show the plate number
- Only show "No vehicle assigned" if neither a vehicle nor a vehicle model exists

==================================================
REQUIRED DISPLAY LOGIC
==================================================

For the "Vehicle & Customer" cell in Bookings list:

Case 1:
If booking has assigned specific vehicle:
- Show: Vehicle Model Name · Plate Number
Example:
Cruze · BB505KK

Case 2:
If booking has no assigned specific vehicle, but has vehicle model:
- Show: Vehicle Model Name
Example:
Toyota Camry XV50

Case 3:
If booking has neither specific vehicle nor vehicle model:
- Show:
No vehicle assigned

Customer name should remain visible underneath as it already is.

If booking source is website and model came from website booking flow, it must also display correctly using the same fallback logic.
