Task #273 — Let staff manage extras on existing bookings from Booking Detail.

Goal:
Allow CRM staff to add, update quantity, and remove optional extras on an existing booking from Booking Detail.

Important business decision:
Do NOT automatically change the booking total amount when extras are added/removed/updated.
Booking amount must remain staff-controlled.
If helpful, UI can show a small note like:
"Extras changed. Review booking amount manually if needed."
But do not recalculate or overwrite totalAmount automatically.

Required functionality:
1) Booking Detail should show current extras.

Recommended backend behavior:
- Prefer one simple endpoint that replaces the booking's extras list atomically:
  PATCH /admin/bookings/:id/extras
  body: { extras: [{ extraId: number, quantity: number }] }
- In one transaction:
  - validate all extraIds are active
  - validate quantities
  - delete existing booking_extra rows for this booking
  - insert new rows with DB-fetched price/pricing_type/max_days
- Return updated booking extras or updated booking detail.
- Do not touch booking totalAmount.
