Current business issue:
The current homepage pickup/dropoff location dropdown groups locations by city and includes Hotel Delivery as a separate location. This is confusing because Hotel Delivery is a service option, not a core location. We want customers to select the city Downtown location first, then choose Delivery Service if they need hotel/address delivery.

Required location dropdown order:
Airports:
1. Tbilisi International Airport
2. Kutaisi International Airport
3. Batumi International Airport

Downtowns:
1. Tbilisi Downtown
2. Kutaisi Downtown
3. Batumi Downtown

Hotel Delivery should be removed from the pickup/dropoff location dropdown options.

Required Delivery Service behavior:
1. If the selected pickup location is a Downtown location, show a checkbox/option labelled:
   "Delivery Service"
2. If the customer checks Delivery Service for pickup, then in the customer/details step, show a required field for pickup delivery address / hotel address.
3. If Same location return is disabled and the selected dropoff/return location is a Downtown location, show a similar return-side Delivery Service option.
4. If the customer checks Delivery Service for return, then in the customer/details step, show a required field for return collection address / hotel address.
5. Airport locations should not show Delivery Service by default.
6. If the customer changes from Downtown to Airport, clear or hide the Delivery Service option/address for that side so stale delivery data is not submitted.

Text:
- Use the visible label "Delivery Service" near the search form.
- In customer/details fields, use clear labels such as:
  "Pickup delivery address / hotel"
  "Return collection address / hotel"
or better wording if existing style already has labels.
