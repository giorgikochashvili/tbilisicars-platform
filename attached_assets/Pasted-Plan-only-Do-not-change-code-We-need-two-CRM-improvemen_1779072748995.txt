In Dashboard Operations, the vehicle license plate badge is readable in dark/night mode, but almost disappears in light/day mode.
Likely cause: plate badge uses dark-mode-friendly classes such as light text on a light background.

- Light mode should use darker text and visible neutral background/border.
- Dark mode should keep the current readable look.
- Apply to desktop and mobile plate badges.
- This should be styling-only, likely Dashboard.tsx only.
