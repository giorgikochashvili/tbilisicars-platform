==================================================
CURRENT PROBLEM
==================================================

In the Dashboard "Fleet Timeline — Next 7 Days", a booking that spans multiple dates is currently rendered as separate small cells/blocks for each day.

Example:
If a booking runs from Apr 1 to Apr 4, the timeline currently shows:
- one small block on Apr 1
- one small block on Apr 2
- one small block on Apr 3
- one small block on Apr 4

This is visually incorrect.

Also:
- Clicking a booking segment in the Fleet Timeline should open that booking
- In Light Mode, the text/name inside the booking bar/cell is too light/white and is hard to read; in Light Mode it must be dark/black or otherwise high-contrast and clearly readable

==================================================
REQUIRED BEHAVIOR
==================================================

PART 1 — Continuous booking bar across the booked date range

A booking spanning multiple days must render as one continuous horizontal bar across the timeline grid from start day to end day.

Expected behavior:
- If booking starts on Apr 1 and ends on Apr 4, show one connected bar spanning Apr 1 → Apr 4
- Do not render 4 disconnected mini cells
- The bar should visually occupy the correct grid span across the relevant day columns
- Keep the row aligned to the booked vehicle
- Preserve the current timeline layout and style language

Important:
- Respect the visible 7-day window only
- If a booking starts before the visible window, clamp the bar to the first visible day
- If a booking ends after the visible window, clamp the bar to the last visible day
- If a booking is fully outside the visible window, do not render it

==================================================
PART 2 — Clicking a timeline booking bar must open that booking

When the user clicks the rendered booking bar in the Fleet Timeline:
- open the corresponding booking detail
- reuse the existing booking detail route/modal/dialog pattern already used elsewhere in CRM
- do not invent a new navigation pattern if booking detail already exists in a dialog/modal

- if it uses route-based navigation, use the existing supported route

Goal:
A staff member can visually see the booked range and directly open the booking from the timeline.

==================================================
PART 3 — Light Mode text contrast fix inside Fleet Timeline booking bars

Current issue:
In Light Mode, the booking label/name inside the timeline bar/cell is too light/white and is difficult to read.

Required fix:
- In Light Mode, the text inside timeline booking bars must be dark and clearly readable
- Use theme-aware styling, not hardcoded one-off hacks if possible
- Do not break Dark Mode text contrast
- Preserve the current visual identity of the booking bars while ensuring accessibility/readability

Preferred result:
