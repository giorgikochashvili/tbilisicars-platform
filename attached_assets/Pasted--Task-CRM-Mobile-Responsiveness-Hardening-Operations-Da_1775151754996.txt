# Task — CRM Mobile Responsiveness Hardening + Operations Dashboard UX Improvements
You are working inside the existing Tbilisicars CRM monorepo built in Replit. This is NOT a redesign from scratch. This is a careful responsive-hardening and dashboard usability task for the CRM admin UI, focused on mobile usability, compactness, dashboard clarity, and preserving all existing working logic.

Important constraints:
- Do NOT change backend/API/business logic unless absolutely required for rendering or harmless UI state persistence.
- Do NOT refactor unrelated modules.
- Do NOT break desktop layout.
- Do NOT remove any existing working functionality.
- Prefer targeted edits in CRM frontend components/styles/state only.
- Preserve current dark premium visual style.
- All current modules must remain functional.
- This task is about responsive layout stabilization, compact rendering, dashboard usability improvements, and persistent UI state.

## Goal
Make the CRM mobile version feel intentionally designed for phones, not just desktop squeezed into a small screen. Also improve the Operations Dashboard so it is clearer and more useful on desktop and mobile, without changing the underlying operational logic.
