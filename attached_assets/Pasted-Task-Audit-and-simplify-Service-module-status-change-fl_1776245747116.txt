Task: Audit and simplify Service module status change flow for operational use

Context:
This is a live production-connected monorepo fully built in Replit. We have already stabilized major booking, dashboard, email/PDF, customer cabinet, CRM booking edit, and tasks flows. Now we want to improve the Service module for day-to-day staff operations.

CRITICAL RULES:
- Do NOT refactor architecture
- Do NOT redesign the whole Service module
- Do NOT implement changes yet unless real issues are identified
- First map the current status-change flow and identify only real operational problems
- Keep any eventual fix minimal and surgical

Goal:
Ensure service record status can be changed easily, clearly, and reliably in everyday CRM use.

Audit Scope:

1. Current status-change entry points
- Identify where service status can currently be changed:
  - service list
  - service detail
  - edit modal/form
- Confirm whether there are multiple different status-change paths

2. Persistence flow
- Identify backend route/service used when service status changes
- Confirm whether status changes persist correctly
- Check whether other fields are unnecessarily required just to change status

3. Operational friction
Focus on real usability issues such as:
- too many clicks just to change status
- status only editable through full edit form
- unclear current status
- save flow too heavy for a simple status change
- mismatch between list and detail views

4. Failure/mismatch risks
- Identify any silent failure paths
- Identify if status appears changed in UI but not actually saved
- Identify if different screens behave differently

5. Real issues only
Do not suggest redesign unless clearly necessary.
Only identify real operational problems and propose minimal fixes.

Output format:
A. Exact frontend flow (pages/components/hooks)
B. Exact backend flow (routes/services/functions)
C. Real issues found only
D. Minimal fix plan only for real issues
E. If no real issues are found, explicitly say: "No fixes required"
