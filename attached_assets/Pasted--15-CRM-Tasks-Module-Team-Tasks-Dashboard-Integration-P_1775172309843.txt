#15 - CRM Tasks Module: Team Tasks, Dashboard Integration, Progress Tracking

IMPORTANT:
This is an existing fully working Tbilisicars CRM + Website project built in Replit.
DO NOT break or refactor existing systems unnecessarily.
DO NOT change existing logic (auth, bookings, fleet, services, dashboard, website).
ONLY extend the system cleanly by adding this module.

----------------------------------------

WHAT & WHY
Add a new Tasks module to the CRM to manage internal team operations.

Admins/managers should:
- create tasks
- assign them to staff
- set priority, status, progress %, and deadlines

Staff should:
- see their tasks on Dashboard (My Tasks widget)
- open tasks
- update progress %
- change status
- add comments
- complete tasks

This must be backend-persisted and production-ready.

----------------------------------------

SCOPE

1) SIDEBAR
Add new item:
- Tasks

Keep existing sidebar behavior unchanged.

----------------------------------------

2) DATABASE / BACKEND

Create task system with fields:
- id
- title
- description
- createdByAdminId
- assigneeAdminId
- priority (Low / Medium / High / Urgent)
- status (To Do / In Progress / Waiting / Done / Canceled)
- progressPercent (0–100)
- startDate (nullable)
- dueDate (nullable)
- relatedType (nullable)
- relatedId (nullable)
- completedAt (nullable)
- createdAt
- updatedAt

Also create:
- task_comments table
- task_activity_log table

----------------------------------------

3) TASK CREATION

Create modal/form with:
- Title (required)
- Description
- Assignee
- Priority
- Status
- Progress % (default 0)
- Start date
- Due date
- Optional related entity:
  (Booking / Vehicle / Service / Customer / Parking)

Rules:
- progress must be 0–100
- if status = Done → progress = 100
- dueDate >= startDate
