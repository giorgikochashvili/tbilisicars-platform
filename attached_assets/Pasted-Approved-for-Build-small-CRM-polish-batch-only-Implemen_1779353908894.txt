Item 1 — Deposit fields in Add Payment form

Goal:
Inside Booking Detail → Payment History → Add Payment form, add simple deposit metadata fields:
- Deposit Amount
- Deposit Currency

Do not add:
- “Deposit Information” header
- explanatory/helper text
- any warning text

Keep Notes exactly as it is.

Business rules:
- Deposit is NOT a payment.
- Deposit must NOT create booking_payment rows.
- Deposit must NOT create accounting_entries rows.
- Deposit must NOT count toward Total Paid.
- Deposit must NOT reduce Remaining Balance.
- Deposit must NOT affect paymentStatus.
- Deposit source of truth is only booking.deposit + booking.depositCurrency.

Implementation:
- Extend the Add Payment form state with depositAmount and depositCurrency.
- When Add Payment opens, initialize depositAmount/depositCurrency from the current booking:
  - depositAmount = booking.deposit ?? ""
  - depositCurrency = booking.depositCurrency ?? "NONE"
- Show Deposit Amount and Deposit Currency as a normal row in the existing form grid, preferably near Notes / bottom of form before Save/Cancel.
- Deposit Currency options should match existing Booking Overview behavior:
  - NONE
  - GEL
  - USD
  - EUR

Save behavior:
When staff clicks Save Payment:
1. Save the payment exactly as before using the existing payment POST.
2. If depositAmount/depositCurrency changed compared to current booking values, then call PATCH /admin/bookings/:id with only:
   - deposit
   - depositCurrency
3. Then refresh payments and booking as already done.
4. If payment POST succeeds but deposit PATCH fails, do not rollback the payment. Show a separate destructive toast for deposit update failure.
5. If deposit fields are unchanged, do not send the second PATCH.

Important:
- Do not include deposit fields in the payment POST body.
- Do not modify payment summary calculation logic.
- Do not modify getBookingPaymentSummary or backend payment services.
- Do not create any accounting entry from deposit.
- Payment Summary must show the updated Deposit Amount + currency after save.
- Booking Overview must show the same saved deposit values.
