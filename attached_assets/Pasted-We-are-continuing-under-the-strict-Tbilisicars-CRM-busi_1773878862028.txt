==================================================
BLOCK 15 GOAL
==================================================

Create a complete **Vehicle Detail operational page** that acts as the central information hub for a specific vehicle.

Operations staff must be able to open a vehicle and immediately understand:

- vehicle identity
- current status
- current location
- booking history
- service history
- mileage context
- financial/service context where relevant

This page must consolidate data from existing modules without duplicating logic.

==================================================
A. VEHICLE DETAIL PAGE ACCESS
==================================================

Vehicle detail must open from:

- Fleet list
- Fleet Calendar / Timeline
- Service module
- Booking vehicle links where available

Clicking a vehicle should open the Vehicle Detail page or modal.

The page must load using the vehicle ID.

==================================================
B. VEHICLE HEADER INFORMATION
==================================================

At the top of the page show a clear vehicle identity panel:

Required fields:

- Brand
- Model
- License plate
- Vehicle status (Available / Reserved / Rented / Maintenance / Inactive)
- Current region/location
- Current mileage (if stored)
- Vehicle ID

Optional if already present:
- vehicle photo

This section must be visually clear and compact.

==================================================
C. CURRENT BOOKING CONTEXT
==================================================

If the vehicle is currently assigned to an active booking:

Show a small "Current Booking" section including:

- booking reference
- customer name
- pickup location
- dropoff location
- pickup date
- dropoff date
- booking status

Provide a link to open the booking.

If no active booking exists, display:

"No active booking"

==================================================

==================================================

Show booking history for this vehicle.

Table columns:

- booking ID
- customer
- pickup date
- dropoff date
- booking status

Do NOT reimplement booking logic.
Use existing booking data.
